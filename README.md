# Server Performance Stats

## Project URL

https://roadmap.sh/projects/server-stats

## Overview

This project analyses Linux server performance statistics using Bash scripting.

## Features

- CPU usage
- Memory usage
- Disk usage
- Top CPU-consuming processes
- Top memory-consuming processes
- Uptime
- OS version

## Technologies Used

- Bash scripting
- Linux commands

## Run Script

```bash
chmod +x server-stats.sh
./server-stats.sh
```
